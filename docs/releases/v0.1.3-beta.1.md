# Craft for VS Code — 0.1.3 beta 1

An independent community preview for installation and testing. This is not an official ArtCraft product and is not published to an extension marketplace.

## Install

Requires desktop VS Code 1.102 or newer, or a compatible Cursor build. No Rust, Node.js or standalone Craft application is required.

1. Download the desired VSIX files and `SHA256SUMS` from [this prerelease](https://github.com/yairkl/craft-vscode/releases/tag/v0.1.3-beta.1).
2. Choose **Extensions → … → Install from VSIX…**, select each extension you want and reload. To use Remote SSH, install the desired extensions on the SSH host and reload the remote window.
3. Open an XLSX, CSV, DOCX, PPTX or PDF file. For SVG or `.vectorcraft`, choose **Reopen Editor With… → Craft Vector**. Install the five individual VSIX files before the optional Suite pack.

| Installer | Application |
| --- | --- |
| `craft-spreadsheets-0.1.4.vsix` | Spreadsheets |
| `craft-word-0.1.3.vsix` | Word documents |
| `craft-powerpoint-0.1.3.vsix` | Presentations |
| `craft-pdf-0.1.3.vsix` | PDF |
| `craft-vector-0.1.3.vsix` | Vector drawings |
| `craft-suite-0.1.3.vsix` | Optional extension pack |

## What's new

- The default file size limit is 256 MiB, configurable per app up to 1024 MiB; for example, `craft.spreadsheets.maxFileSizeMiB` and `craft.pdf.maxFileSizeMiB`. Large or compressed files can require substantially more memory than their size on disk. The limit is not a performance guarantee.
- Spreadsheet agent sessions pass workbook bytes directly instead of encoding them in MCP messages. Agent save copies refuse to overwrite existing files.
- Document transfers avoid redundant copies where safe; cache refreshes are coalesced during rapid edits. Recovery backups use a compact binary format and can still read older JSON backups.
- The project owner has verified MCP discovery in VS Code and Cursor. Individual real-client editing and remote scenarios still need broader validation.
- Upstream patches have been organized into reviewable subsystem groups; they remain downstream patches pending upstream review.

## Preview limits

Test on copies of valuable files. Complex Office/PDF/SVG fidelity, large-file performance, printing and signing, image clipboard transfer, full accessibility and IME support, and arbitrary platform or font coverage remain incomplete. Password-protected documents and legacy `.doc`/`.ppt` are unsupported. Unsaved text or formula drafts that cannot yet be serialized cannot be recovered after a crash.

Older extension versions cannot read the new binary backups if the extension is downgraded before recovery. Application shortcuts can still conflict with editor shortcuts. Cursor and macOS-to-Remote SSH behavior require further testing. For available language coverage see [language support](../languages.md). Report problems with editor and OS versions and a shareable reproduction in the [issue tracker](https://github.com/yairkl/craft-vscode/issues).
