# Craft Editors — 0.1.6 beta 1

An independent community preview for VS Code and compatible Cursor builds. This project integrates the Craft applications; it is not an official ArtCraft product and is not published to an extension marketplace.

## Install or update

Requires desktop VS Code 1.102 or newer, or a compatible Cursor build. No Rust, Node.js or standalone Craft application is required.

1. Download the desired VSIX files and `SHA256SUMS` from [this prerelease](https://github.com/yairkl/craft-editors/releases/tag/v0.1.6-beta.1).
2. In Extensions, choose **… → Install from VSIX…**, select each file and reload when prompted. For Remote SSH, install the extensions on the SSH host and reload the remote window.
3. Open a supported document. For SVG or `.vectorcraft`, choose **Reopen Editor With… → Craft Vector**. Install the five individual VSIX files before the optional Craft Editors pack.

| Installer | Extension | Files |
| --- | --- | --- |
| `craft-spreadsheets-0.1.6.vsix` | Craft Spreadsheets | `.xlsx`, `.csv` |
| `craft-word-0.1.6.vsix` | Craft Documents | `.docx` |
| `craft-powerpoint-0.1.6.vsix` | Craft Presentations | `.pptx` |
| `craft-pdf-0.1.6.vsix` | Craft PDF | `.pdf` |
| `craft-vector-0.1.6.vsix` | Craft Vector | `.svg`, `.vectorcraft` |
| `craft-suite-0.1.6.vsix` | Craft Editors | Optional extension pack |

## What's new

- The extensions have a consistent naming family and original icons. Extension IDs remain the same as in earlier previews.
- The embedded applications are updated to GridCraft 0.13.0, WordCraft 0.12.0, DeckCraft 0.12.0, PdfCraft 0.15.0 and VectorCraft 0.18.0.
- The project repository is now [craft-editors](https://github.com/yairkl/craft-editors).

## Preview limits

Test with copies of valuable files. Complex Office, PDF and SVG fidelity, large-file performance, printing and signing, image clipboard transfer, accessibility, IME input, and broader platform and font coverage remain incomplete. Password-protected documents and legacy `.doc` and `.ppt` files are unsupported. An unfinished draft that cannot be serialized may not be recoverable after a crash.

The default file limit is 256 MiB and can be configured per editor up to 1024 MiB. Large or compressed files may require substantially more memory than their file size. Full-screen slideshow and Presenter View are not supported. MCP discovery has been verified in VS Code and Cursor; broader real-client editing and remote workflows still need validation. See [language support](../languages.md) and [report issues](https://github.com/yairkl/craft-editors/issues) with your editor and OS versions and a shareable reproduction.
