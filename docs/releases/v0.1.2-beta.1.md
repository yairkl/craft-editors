# Craft for VS Code — 0.1.2 beta 1

Third public installation and testing preview of the independent community integration. This is not an official Storytold/ArtCraft product and is not published to an extension marketplace.

## Install

Requires desktop VS Code 1.102 or newer, or a compatible Cursor build. No Rust, Node.js or standalone Craft application is required.

1. Download the desired VSIX files and `SHA256SUMS` from [this prerelease](https://github.com/yairkl/craft-vscode/releases/tag/v0.1.2-beta.1).
2. In the editor, choose **Extensions → … → Install from VSIX…**, select each extension you want and reload. For command-line installation, use `code --install-extension <file>.vsix --force` or Cursor's corresponding command.
3. Open an XLSX, CSV, DOCX, PPTX or PDF file. For SVG or `.vectorcraft`, choose **Reopen Editor With… → Craft Vector**. Install the five individual VSIX files before the optional Suite pack.

| Installer | Application |
| --- | --- |
| `craft-spreadsheets-0.1.3.vsix` | Spreadsheets |
| `craft-word-0.1.2.vsix` | Word documents |
| `craft-powerpoint-0.1.2.vsix` | Presentations |
| `craft-pdf-0.1.2.vsix` | PDF |
| `craft-vector-0.1.2.vsix` | Vector drawings |
| `craft-suite-0.1.2.vsix` | Optional extension pack |

## What's new

- Each app exposes its upstream MCP tools through its extension host for supported agent clients. Agents can work with open editors and closed files. PDF exposes a reviewed subset of tools; see the individual extension READMEs for setup and limits.
- CSV sessions keep workbook-only changes recoverable and show **Save as XLSX** only when the current edits require it. Value edits and sorting can still be saved to CSV.
- Embedded keyboard events can reach the host editor's shortcut system. Keyboard undo/redo is routed once while toolbar history continues to use the host.
- Cross-platform tests cover editor rendering, native keyboard input and clipboard, undo/redo, save/reopen, themes, Hebrew font coverage, CSV and closed-file agent editing. Release checks include Linux, Windows and macOS.

## Preview limits

Test on copies of valuable files. Complex Office/PDF/SVG fidelity, printing and signing, image clipboard transfer, full accessibility and IME support, and arbitrary platform or font coverage remain incomplete. Files are limited to 32 MiB; password-protected documents and legacy `.doc`/`.ppt` are unsupported. Unsaved text or formula drafts that cannot yet be serialized cannot be recovered after a crash.

Real Copilot and Cursor MCP discovery has not been fully validated. Application shortcuts can still conflict with editor shortcuts. Cursor and macOS-to-Remote SSH behavior require further testing. For available language coverage see [language support](../languages.md). Report problems with editor and OS versions and a shareable reproduction in the [issue tracker](https://github.com/yairkl/craft-vscode/issues).
