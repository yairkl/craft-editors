# Craft for VS Code — 0.1.1 beta 1

Second installation/testing preview; upgrades the 0.1.0 installers. Independent community integration based on Storytold's open-source Crafting Apps; not an official or endorsed Storytold/ArtCraft release. No Marketplace publication.

## Install

Requires desktop VS Code 1.102 or newer. No Rust, Node.js or external application installation is needed.

1. Download the desired `.vsix` files from [this prerelease](https://github.com/yairkl/craft-vscode/releases/tag/v0.1.1-beta.1). `SHA256SUMS` lets you verify the downloads.
2. In VS Code: **Extensions → … → Install from VSIX…**. Install each program you want, then reload VS Code. CLI alternative: `code --install-extension craft-spreadsheets-0.1.1.vsix --force` (substitute another package as needed).
3. Open `.xlsx`, `.csv`, `.docx`, `.pptx` or `.pdf`. For `.svg`/`.vectorcraft`, use **Reopen Editor With… → Craft Vector**; optionally configure it as the default. SVG's usual text editor remains available.
4. For Suite, install all five individual VSIX files first, then `craft-suite-0.1.1.vsix`. The pack cannot fetch unpublished development IDs from Marketplace.

| Installer | Includes |
| --- | --- |
| `craft-spreadsheets-0.1.1.vsix` | GridCraft spreadsheet editor only |
| `craft-word-0.1.1.vsix` | WordCraft document editor only |
| `craft-powerpoint-0.1.1.vsix` | DeckCraft presentation editor only |
| `craft-pdf-0.1.1.vsix` | PdfCraft PDF editor only |
| `craft-vector-0.1.1.vsix` | VectorCraft SVG/native drawing editor only |
| `craft-suite-0.1.1.vsix` | Optional pack, no renderer |

## Changes since the first beta

- CSV editing joins XLSX in Craft Spreadsheets, including delimiter detection/preservation, quoted and multiline fields, Unicode, Save As and Revert. CSV holds one sheet of values; formatting and formulas are not retained as workbook features. Additional sheets must be removed before CSV saving. Native value inference may normalize numeric/date fields.
- PDF opens in the native Read workspace with tool panels closed. Editing remains available when chosen; Ctrl+wheel zoom and normal scrolling remain supported.
- Spreadsheets, Word and PowerPoint start with command ribbons collapsed. Tabs stay visible. Click a tab in Spreadsheets/PowerPoint; double-click one in Word to expand its tools.
- Fine spreadsheet Ctrl+wheel zoom lives entirely in the VS Code adapter. Ordinary scrolling, pinch gestures, zoom buttons and keyboard shortcuts retain upstream behavior. Buttons/shortcuts use the original ten-point steps; Ctrl+wheel uses five points.
- Unsupported slideshow/Presenter View and recording launches are disabled in the embedded PowerPoint editor. They previously opened a child window over the audience slide. Use View > Reading View here, or save the PPTX and present in a standalone application for fullscreen/multiple displays.
- Native replacement-input tests now distinguish replacing a cell from continuing a live draft, preventing the intermittent concurrency-test append failure.

## What to test

Try CSV open/edit/save/reopen, ongoing text/formula entry with autosave, native ribbon expansion/collapse, fine Ctrl+wheel and ordinary scrolling. Check Word typing after Undo/Redo and PDF editing after starting in Read mode. Report regressions with an original shareable sample and OS/editor version.

Existing features include native Save/Save As, Undo/Redo, Revert, recovery, live light/dark themes, independent VectorCraft support and verified Hebrew/niqqud in all five apps. The [language guide](../languages.md) distinguishes font coverage, editing, translated menus and proofing.

## Limits

Test on copies of valuable files. The engines and integration are early previews; arbitrary Office/PDF/SVG fidelity is not guaranteed. SVG is imported and rewritten, so XML formatting and unsupported features may change. Files are limited to 32 MiB; legacy `.doc`/`.ppt` are not registered. Password-protected documents, printing/signing, external file pickers, image clipboard, multi-document combine/export workflows, synchronized views and full accessibility/IME coverage are outside validated scope. All five apps bundle a pinned OFL Hebrew fallback. See [language support](../languages.md); additional user font import is not exposed yet. Other font/script coverage is limited; external craft-fonts is not bundled.

Unfinished PDF text/form drafts defer autosave and backup until committed; incomplete spreadsheet formulas similarly defer. A process crash before such drafts become serializable cannot recover their text. Keep them open until finished/saved. Saved document history is local to the live editor session.

Linux with minimum/current desktop VS Code, a simulated remote filesystem and actual Remote SSH to a separate Ubuntu container are tested. Remote render/edit/save/reopen, Undo/Redo, Save As, Revert and backups pass in all five apps. Windows/macOS, WSL, WAN/jump-host/reconnect scenarios still need beta testing; browser-hosted VS Code is not supported. No telemetry or document processing service is added by this integration.

Report bugs in [our issue tracker](https://github.com/yairkl/craft-vscode/issues), including OS, VS Code and extension version, file type, steps, expected/actual behavior and an original shareable reproduction file. Avoid uploading confidential documents. To roll back, reinstall the affected 0.1.0 VSIX from [the first beta](https://github.com/yairkl/craft-vscode/releases/tag/v0.1.0-beta.1) with `--force`, or use **Reopen Editor With…** to choose another editor; keep original test copies.
