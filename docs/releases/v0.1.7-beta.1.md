# Craft Editors — 0.1.7 beta 1

An independent community preview for VS Code and compatible Cursor builds. This is not an official ArtCraft product. Distribution remains through GitHub VSIX downloads; marketplace publisher identity and store publication are still pending.

## Install or update

Requires desktop VS Code 1.102 or newer, or a compatible Cursor build. Download the installers and `SHA256SUMS` from [this prerelease](https://github.com/yairkl/craft-editors/releases/tag/v0.1.7-beta.1). In Extensions, select **… → Install from VSIX…**, choose each desired installer and reload. No Rust, Node.js or standalone Craft installation is needed. For Remote SSH, install on the SSH host.

| Installer | Files |
| --- | --- |
| `craft-spreadsheets-0.1.7.vsix` | `.xlsx`, `.csv`, `.tsv` |
| `craft-word-0.1.7.vsix` | `.docx`, opt-in `.md` |
| `craft-powerpoint-0.1.7.vsix` | `.pptx` |
| `craft-pdf-0.1.7.vsix` | `.pdf` |
| `craft-vector-0.1.7.vsix` | Opt-in `.svg`, `.vectorcraft` |
| `craft-suite-0.1.6.vsix` | Unchanged optional extension pack |

Install the five apps before the optional Suite. Existing extension IDs are preserved. The unchanged Suite keeps version 0.1.6 and can group the newer app versions. Choose **Reopen Editor With…** for optional Markdown and vector views.

## What's new since 0.1.6 beta 3

- Open documents refresh after external file changes, with protections for drafts, pending saves and undo history.
- Craft Documents offers opt-in Markdown editing with conservative conversion/save checks and a DOCX-copy path for unsupported features.
- Spreadsheets supports TSV and convenient CSV/text switching. SVG has convenient text/vector switching.
- Updated embedded apps: GridCraft 0.19.1, WordCraft 0.18.1, DeckCraft 0.18.1, PdfCraft 0.21.1 and VectorCraft 0.24.1.
- Installers include explicit dependency-to-notice associations, pinned supplements for notices omitted from registry archives, license selections, renderer provenance and the upstream modification patches. See [the distribution review](../distribution-audit.md).

## Preview limits

Test with copies of valuable files. Complex Office/PDF/SVG fidelity, accessibility, IME input, image clipboard transfer, printing/signing, large-file performance and broader real-client MCP workflows remain incompletely validated. Password-protected documents and legacy `.doc`/`.ppt` are unsupported. Full-screen slideshow and Presenter View are unsupported. Unfinished drafts that cannot be serialized may not survive a crash.

The default file limit is 256 MiB per editor, configurable up to 1024 MiB. Large or compressed documents can consume substantially more memory than their file size. Markdown/CSV/TSV cannot retain every rich document/workbook feature; use the supported copy-to-DOCX/XLSX flows when prompted. See [language coverage](../languages.md).

Release CI validates VS Code across Linux, macOS and Windows, plus Linux Remote SSH. It does not establish compatibility with every Cursor build or validate store installation/update. See [publication requirements](../publication.md). Report reproducible issues without private documents in [the issue tracker](https://github.com/yairkl/craft-editors/issues); use [private vulnerability reporting](../../SECURITY.md) for security issues.
