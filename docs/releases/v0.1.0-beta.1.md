# Craft for VS Code — 0.1.0 beta 1

First public installation/testing preview. Independent community integration based on Storytold's open-source Crafting Apps; not an official or endorsed Storytold/ArtCraft release. No Marketplace publication.

## Install

Requires desktop VS Code 1.102 or newer. No Rust, Node.js or external application installation is needed.

1. Download the desired `.vsix` files from [this prerelease](https://github.com/yairkl/craft-vscode/releases/tag/v0.1.0-beta.1). `SHA256SUMS` lets you verify the downloads.
2. In VS Code: **Extensions → … → Install from VSIX…**. Install each program you want, then reload VS Code. CLI alternative: `code --install-extension craft-spreadsheets-0.1.0.vsix --force` (substitute another package as needed).
3. Open `.xlsx`, `.docx`, `.pptx` or `.pdf`. For `.svg`/`.vectorcraft`, use **Reopen Editor With… → Craft Vector**; optionally configure it as the default. SVG's usual text editor remains available.
4. For Suite, install all five individual VSIX files first, then `craft-suite-0.1.0.vsix`. The pack cannot fetch unpublished development IDs from Marketplace.

| Installer | Includes |
| --- | --- |
| `craft-spreadsheets-0.1.0.vsix` | GridCraft spreadsheet editor only |
| `craft-word-0.1.0.vsix` | WordCraft document editor only |
| `craft-powerpoint-0.1.0.vsix` | DeckCraft presentation editor only |
| `craft-pdf-0.1.0.vsix` | PdfCraft PDF editor only |
| `craft-vector-0.1.0.vsix` | VectorCraft SVG/native drawing editor only |
| `craft-suite-0.1.0.vsix` | Optional pack, no renderer |

## What to test

- Native editing, VS Code Save/Save As, Undo/Redo, Revert and recovery.
- PDF page/text/comment tools; **Ctrl+wheel** zooms, ordinary wheel scrolls. PDF page rotation/save/reopen is covered by integration tests.
- Vector drawing tools and SVG/native `.vectorcraft` save/reopen. Save As keeps the source format.
- Word: Undo/Redo retains typing focus. All five apps bundle Noto Sans Hebrew and cover Hebrew/niqqud native edits and save/reopen; Word also covers a mixed RTL fixture.
- Live light/dark theme changes; high contrast maps to the native light/dark palette.
- Spreadsheet fine zoom (5 percentage points), autosave while typing text/formulas, worksheet tabs.

## Limits

Test on copies of valuable files. The engines and integration are early previews; arbitrary Office/PDF/SVG fidelity is not guaranteed. SVG is imported and rewritten, so XML formatting and unsupported features may change. Files are limited to 32 MiB; legacy `.doc`/`.ppt` are not registered. Password-protected documents, printing/signing, external file pickers, image clipboard, multi-document combine/export workflows, synchronized views and full accessibility/IME coverage are outside validated scope. All five apps bundle a pinned OFL Hebrew fallback. See [language support](../languages.md); additional user font import is not exposed yet. Other font/script coverage is limited; external craft-fonts is not bundled.

Unfinished PDF text/form drafts defer autosave and backup until committed; incomplete spreadsheet formulas similarly defer. A process crash before such drafts become serializable cannot recover their text. Keep them open until finished/saved. Saved document history is local to the live editor session.

Linux with minimum/current desktop VS Code, a simulated remote filesystem and actual Remote SSH to a separate Ubuntu container are tested. Remote render/edit/save/reopen, Undo/Redo, Save As, Revert and backups pass in all five apps. Windows/macOS, WSL, WAN/jump-host/reconnect scenarios still need beta testing; browser-hosted VS Code is not supported. No telemetry or document processing service is added by this integration.

Report bugs in [our issue tracker](https://github.com/yairkl/craft-vscode/issues), including OS, VS Code and extension version, file type, steps, expected/actual behavior and an original shareable reproduction file. Avoid uploading confidential documents. To roll back, uninstall the affected beta extension or use **Reopen Editor With…** to choose another editor; keep original test copies.
