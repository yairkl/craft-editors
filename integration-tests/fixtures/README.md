# Smoke documents

These files are original fixtures generated by `scripts/generate-fixtures.py` and covered by the repository MIT license. They contain no third-party documents or embedded font files.

- `minimal.xlsx`: sheet `Smoke`, `A1` = `Craft smoke fixture`, `B2` = `42`, `B3` = formula `B2*2` with cached value `84`. The future edit round trip should change `B2` to `21`, then verify `B3` recalculates to `42` after save/reopen.
- `minimal.pdf`: one US Letter page containing `Craft smoke fixture` using the standard Helvetica font reference. No font program is embedded.

Run `npm run fixtures` to regenerate, or `npm run fixtures:check` to compare without changing files. Generation uses only Python's standard library, fixed ZIP metadata and stored entries. These are basic smoke inputs; malformed, large, encrypted and format-fidelity coverage must be added as the engines land.

The current integration tests verify exact binary transport to a real VS Code webview, read-only operation and use of a non-file filesystem provider. They do not yet verify Craft rendering, calculation or editing.
