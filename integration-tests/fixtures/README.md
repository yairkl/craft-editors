# Smoke documents

These files are original fixtures generated by `scripts/generate-fixtures.py` and covered by the repository MIT license. They contain no third-party documents or embedded font files.

- `minimal.xlsx`: sheet `Smoke`, `A1` = `Craft smoke fixture`, `B2` = `42`, `B3` = formula `B2*2` with cached value `84`. The future edit round trip should change `B2` to `21`, then verify `B3` recalculates to `42` after save/reopen.
- `minimal.pdf`: one US Letter page containing `Craft smoke fixture` using the standard Helvetica font reference. No font program is embedded.
- `rendering.xlsx`: two sheets with a merged blue heading, font/fill styles, decimal and percent formats, and a calculated value. It exercises the viewport and worksheet selector.
- `rendering-active.xlsx`: the same workbook saved with its second sheet active; verifies the chooser matches the initially rendered sheet.
- `rendering.pdf`: two US Letter pages with distinct text and vector graphics, exercising page navigation and zoom.

Run `npm run fixtures` to regenerate, or `npm run fixtures:check` to compare without changing files. Generation uses only Python's standard library, fixed ZIP metadata and stored entries. These are basic smoke inputs; malformed, large, encrypted and format-fidelity coverage must be added as the engines land.

The transport suite verifies exact binary delivery. The rendering suite runs actual Craft WASM renderers, verifies formula results and input blocking, switches sheets/pages, resizes/zooms and captures PNGs for visual QA. Source bytes remain unchanged. Editing lifecycle suites are separate from transport/rendering-only checks.

- `minimal.docx`: original blue bold heading and two paragraphs on a letter-sized page.
- `minimal.pptx`: two original slides with blue text headings; no imported templates, images or fonts.

The Office suite exercises native text input, real rendering, undo/redo, Save/reopen, Save As, Revert and recovery for DOCX/PPTX. The spreadsheet editing suite covers the shared host’s failure and concurrent-save behavior.
