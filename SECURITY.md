# Reporting a security vulnerability

Please use [GitHub's private vulnerability reporting](https://github.com/yairkl/craft-editors/security/advisories/new) for suspected vulnerabilities. Include the extension and editor versions, operating system, a description of the impact, and a minimal reproduction using non-sensitive files. Avoid including passwords, credentials or private documents.

If private reporting is unavailable, do not post exploit details in a public issue; contact the repository owner through a private channel instead. There is currently no guaranteed response or fix timeline.

The project is an independent community integration and is distributed as a preview. Security updates apply to the current maintained preview; older VSIX files do not update automatically when installed outside a marketplace. Check [GitHub releases](https://github.com/yairkl/craft-editors/releases) for newer builds.
